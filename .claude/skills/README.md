# Claude Code skills and agents for DeskNotes

| Path | Purpose |
|---|---|
| `skills/desknotes-verify-ubuntu` | Check changes in the real app on Ubuntu with `scripts/verify/` |
| `skills/desknotes-build-from-design` | Build screens from the owner's Claude Design export |
| `agents/desknotes-reviewer.md` | Review diffs for data loss, security and privacy |
| `skills/rust-testing`, `react-testing`, `database-migrations`, `git-workflow` | General guides copied from [ECC](https://github.com/affaan-m/ECC) (MIT, see THIRD_PARTY_NOTICES.md) |

Claude Code picks these up automatically in this repository. `CLAUDE.md` at the root holds
the project rules.
