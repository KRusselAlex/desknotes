# DeskNotes logo

Designed by the project owner in Claude Design ("Logo final 2b"). Released under the
project's MIT license.

| File | Use |
|---|---|
| `desknotes-icon.svg` | App icon, 48 px and larger (sage tile) |
| `desknotes-icon-small.svg` | App icon at 16–32 px: no grip, one checked row |
| `desknotes-mark.svg` | Symbol without tile, next to the "DeskNotes" wordmark |
| `desknotes-mark-mono.svg` | One-colour version |
| `desknotes-mark-inverse.svg` | For dark backgrounds |

The wordmark is "DeskNotes" in the system font, weight 750, letter-spacing −0.025em.
App icons in `src-tauri/icons/` are generated from these files.
